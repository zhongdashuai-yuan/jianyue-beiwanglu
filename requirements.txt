# ★ 版本必须钉在 6.8.x，不要升到 6.9 以上！

#   在冻结进程里会报 "DLL load failed while importing QtCore: 找不到指定的程序"
#   （WinError 127），6.8.0.2 实测打包后可以正常运行。
#   Python 3.13 能装的最老版本就是 6.8.0.2。
